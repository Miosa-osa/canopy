# Agents

This directory contains specialist agent definitions for the Sales Engine workspace.

## Available Agents

- `closer.md` — Late-stage negotiation and close specialist
- `sdr.md` — Top-of-funnel prospecting and qualification specialist

## Format

Each agent file follows the Canopy agent format:

```markdown
# Agent Name

## Role
What this agent does.

## When to Activate
Trigger conditions.

## Capabilities
What it can do.

## Dependencies
Workspace files it needs.
```

Add new agents here as your sales org grows.
