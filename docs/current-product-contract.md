# Current Canopy Product Contract

Effective: 2026-09-08.
Owner: platform.

Canopy currently focuses on a desktop terminal workspace that survives restart.
Named sessions, working directories, git worktrees, terminal restoration, and agent conversation continuity are the intended product scope.
The broader module vision is parked in navigation; existing routes are retained for future activation.
A route existing in source does not establish end-to-end readiness or current sidebar exposure.

`CLAUDE.md` owns agent operating rules.
This document owns current product scope.
`24-workspace-engine.md` owns workspace Engine execution.
`25-review-queue.md` owns Canopy operational review, which is distinct from OptimalEngine Claim-to-Fact review.
`agent-authority.json` supplies the machine-readable ownership graph.

The April foundation plan, phase reports, and wiring audits are historical evidence.
Their completion counts and screenshots do not supersede this scope or prove the current checkout works.
Competitor reports are attribution/reference material, not permission to expand runtime capabilities.
`NOTICE.md` owns attribution records.

Implementation claims require a named code path plus a reproducible test against the checkout being shipped.
A design contract describes required behavior; CI and runtime evidence establish whether that behavior is implemented.
